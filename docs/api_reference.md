# 📖 PolarTwin REST & WebSocket API Reference

The FastAPI backend exposes versioned endpoints under `/api/v1` and WebSocket push streams on `/ws`.

---

## ⚡ REST Endpoints

### 1. Stations & Digital Twin
- `GET /api/v1/stations`: List both stations with summary health and active generation.
- `GET /api/v1/stations/{station_id}`: Full snapshot of in-memory twin state including all asset nodes.
- `GET /api/v1/stations/{station_id}/assets/{asset_id}`: Granular telemetry and health metrics for a specific asset.

### 2. Energy & Forecasting
- `GET /api/v1/stations/{station_id}/energy`: Real-time active generation, demand, and battery SOC breakdown.
- `GET /api/v1/stations/{station_id}/energy/forecast`: 24-hour predictive load demand generated by Random Forest regressor.

### 3. Alerts & Anomaly Management
- `GET /api/v1/stations/{station_id}/alerts`: Filter active alerts by severity (`CRITICAL`, `WARNING`, `INFO`).
- `PATCH /api/v1/alerts/{alert_id}/acknowledge`: Mark an alert acknowledged by the mission operator.

### 4. Inventory & Logistics
- `GET /api/v1/stations/{station_id}/inventory`: Stock levels, depletion rates, and calculated `days_remaining`.

### 5. What-If Scenarios
- `POST /api/v1/stations/{station_id}/scenarios/run`: Execute isolated state cloning and cascade simulation (`generator_failure`, `extreme_weather`, `comms_loss`, `fuel_critical`).

### 6. Grounded AI Assistant
- `POST /api/v1/ai/chat`: Send message thread to Claude AI / local tool-grounded engine.

---

## 🌐 WebSocket Stream
- `GET /ws/stations/{station_id}`: Live real-time bidirectional push channel delivering `TELEMETRY_UPDATE` and `ALERT_CREATED` events every 5 seconds.
